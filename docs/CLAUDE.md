# docs/

이 폴더의 `*.md`는 `scripts/execute.py`가 루트 `CLAUDE.md`와 함께 **매 harness step 프롬프트에 넣는다**. 이 파일도 들어가므로 짧게 둔다.

| 문서 | 정하는 것 |
|---|---|
| `PRD.md` | 무엇을 만드는가 — 목표·사용자·원본·핵심 기능·제외 사항·문제 은행의 기준·디자인 방향 |
| `ARCHITECTURE.md` | 어떻게 짜는가 — 디렉토리 구조·데이터 모델·라우트·데이터 흐름·상태 관리·테스트 경계 |
| `ADR.md` | 왜 그렇게 정했는가 — 결정마다 이유·검토한 대안·트레이드오프. 다른 문서는 ADR 번호로 근거를 가리킨다 |
| `UI_GUIDE.md` | 어떻게 보이는가 — 색·컴포넌트 클래스·도식·레이아웃·타이포그래피와 그 실측값 |

`docs/source/`는 AWS 과목 학습 데이터의 근거 원본이다. 규칙은 `docs/source/CLAUDE.md`에 있고, 그 파일은 주입되지 않는다.
