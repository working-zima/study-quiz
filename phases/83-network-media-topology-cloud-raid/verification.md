## 문항 37 손 검산

37개를 모두 읽어 정답이 하나뿐인지와 해설이 오답마다 까닭을 가르는지 봤다. 계산은 다시 했다.

- n370 완전 메시 장치 6 → 6×5÷2 = 15(오답 30 = 2로 안 나눔, 6 = 링형·성형, 5 = 장치 하나의 링크 수·트리형).
- n385 1TB×3 RAID 0 → 3TB(오답 1TB = RAID 1, 2TB = RAID 5, 1.5TB = 절반을 사본으로 본 착각).
- n387 3TB×2 RAID 1 → 3TB(6TB는 RAID 0).
- 본문 예 RAID 5 2TB×4 → 6TB, RAID 1 2TB×2 → 2TB.
- n363 동기식 TDM 입력 5·데이터 2 → 칸 다섯이 그대로 지나감(아니요).
