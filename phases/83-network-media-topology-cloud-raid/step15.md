# Step 15: fog-sdn

## 배경

phase 83은 네트워크 과목의 `transmission-media`·`network-topology`·`cloud-sdn`·`raid-storage`를 만든다. 전체 계획·결정·공통 규칙은 `phases/83-network-media-topology-cloud-raid/guide.md`에 있다.
**이 step은 `cloud-sdn`의 개념 둘(5 포그 컴퓨팅, 6 SDN)의 글·문항·도식을 함께 만든다.** 둘 다 부모가 없는 개념이다.

기출은 데이터를 먼 데이터 센터로 보내는 대신 생긴 곳 가까이에서 골라 분석하는 구조가 포그 컴퓨팅임을 묻고([기출 2024-05-19 #25] — 오답 그리드·병렬·직렬),
하드웨어가 아니라 소프트웨어로 제어하고 제어 평면과 데이터 평면을 나눠 중앙에서 프로그래밍하는 기술이 SDN임을 묻는다([기출 2024-11-03 #25]·[기출 2025-05-25 #24]·[기출 2026-08-02 #20] — 오답 SDS·SNMP·CLI).

- `src/data/network/topics.json` — **`cloud-sdn`의 앞 개념 넷**(특히 `cloud-computing`·`data-center`), `hub-switch-vlan.switch`·`routing.routing`(장비가 전달을 정하는 일 — 뜻을 맞춘다), `app-protocols-mgmt-security`의 SNMP 개념(있으면 — SNMP와 가를 때 뜻을 맞춘다)

### 3. 도식

#### 3-1. `fog-computing` — `FogLayersDiagram`, JSON 키 `fog-layers`

- 물음형 제목 예: `센서의 데이터는 어디에서 먼저 처리될까?`
- 그릴 것: 아래에 `SENSOR01`~`SENSOR03`, 가운데에 `FOG01`(「공장 안」 그룹 박스 안에 센서와 함께), 위에 「클라우드 데이터 센터」 노드. 센서 → `FOG01`, `FOG01` → 클라우드 경로와, 포그가 없을 때의 센서 → 클라우드 직행 경로(다른 자리로 돌아간다).
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `cloud-only` | 모두 멀리 보내기 | 센서 셋·클라우드와 직행 경로 셋(`FOG01`은 흐림) | 데이터를 모두 먼 데이터 센터까지 보낸다 |
  | `fog` | 가까이에서 먼저 | 센서 셋·`FOG01`·클라우드와 거치는 경로 | `FOG01`이 먼저 걸러 이상한 값은 바로 알리고 요약만 보낸다(본문대로) |

- 요점 테스트: `cloud-only`에서 클라우드로 들어가는 보이는 경로가 셋이고 `FOG01`의 opacity가 0.25다. `fog`에서 클라우드로 들어가는 보이는 경로가 하나이고 그 시작이 `FOG01`이다.

#### 3-2. `sdn` — `SdnPlanesDiagram`, JSON 키 `sdn-planes`

- 물음형 제목 예: `SDN에서는 누가 길을 정하고 누가 패킷을 보낼까?`
- 그릴 것: 위에서 아래로 「응용 프로그램」 → `CTRL01`(「제어 평면」 그룹) → `SW01`~`SW03`(「데이터 평면」 그룹, 280 폭에서 셋을 한 줄에 두되 폭이 모자라면 두 줄로), 그 아래 패킷이 지나는 호스트 둘(예: 보내는 쪽과 `192.0.2.10`). 곁말로 노스바운드·사우스바운드 인터페이스(본문에 쓴 만큼).
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `rule` | 규칙 내려보내기 | 응용 프로그램·`CTRL01`·스위치 셋과 위에서 아래로 가는 경로 | 컨트롤러가 규칙을 정해 스위치에 내려보낸다 |
  | `forward` | 규칙대로 보내기 | 스위치와 호스트 둘, 패킷이 지나는 경로(`CTRL01`은 흐림) | 스위치가 받은 규칙대로 패킷을 내보낸다 — 패킷은 컨트롤러를 지나지 않는다(본문대로) |

- 요점 테스트: `forward`에서 보이는 경로 어느 것도 `CTRL01`을 끝점으로 갖지 않는다. `rule`에서 `CTRL01`에서 나간 보이는 경로가 스위치 셋 모두에 닿는다.

위 도식 설계는 출발점이다. 본문(step 12 결과)과 맞지 않거나 280 폭에 들지 않으면 바꾸되, 바꾼 것과 이유를 summary에 적는다.
