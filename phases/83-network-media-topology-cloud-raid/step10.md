# Step 10: mesh-tree-token-ring

## 배경

phase 83은 네트워크 과목의 `transmission-media`·`network-topology`·`cloud-sdn`·`raid-storage`를 만든다. 전체 계획·결정·공통 규칙은 `phases/83-network-media-topology-cloud-raid/guide.md`에 있다.
**이 step은 `network-topology`의 개념 둘(5 메시형과 트리형, 6 토큰 링)의 글·문항·도식을 함께 만든다.** 5는 `network-topology`에 딸린 개념, 6은 부모가 없는 개념이고 뒤 step의 `fddi`의 부모다.

기출은 메시·트리를 토폴로지 이름 문항의 오답으로 내고([기출 2025-05-25 #20]·[기출 2026-02-01 #18]·[기출 2025-08-24 #22]), 각 노드에게 전송 기회를 차례로 주는 매체 접근 방식이 토큰 링임을 묻는다([기출 2025-05-25 #27] — 오답 CSMA/CD·CSMA·DQDB).

### 3. 도식

#### 3-1. `mesh-tree-topology` — `MeshTreeLinksDiagram`, JSON 키 `mesh-tree-links`

- 물음형 제목 예: `메시형과 트리형은 노드를 어떻게 이을까?`
- 그릴 것: 그룹 박스 둘 — 「완전 메시」 안에 노드 넷(사각형 네 귀퉁이)과 링크 여섯(네 변 + 대각선 둘 — 대각선은 직교 경로로 둘레 바깥을 돌아간다, 다른 노드 상자 안을 지나지 않게), 「트리형」 안에 맨 위 노드 하나·가운데 노드 둘·아래 노드 넷(노드 id는 그룹마다 따로). 280 폭에서 아래 노드 넷이 한 줄에 들지 않으면 두 줄로.
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `full-mesh` | 완전 메시 | 메시 그룹의 노드 넷과 링크 여섯 | 모든 노드 쌍을 바로 잇는다 — 노드 넷이면 링크 여섯 |
  | `tree` | 트리형 | 트리 그룹의 노드 일곱과 링크 | 위에서 아래로 가지를 친다(본문대로) |
  | `tree-cut` | 가지가 끊기면 | 트리 그룹에서 끊긴 가지 아래를 뺀 노드(그 아래는 흐림) | 위 가지가 끊기면 그 아래가 모두 끊긴다(본문에 있을 때만 — 없으면 이 시나리오를 뺀다) |

- 요점 테스트: `full-mesh`에서 보이는 링크 경로가 여섯이고, 메시 노드 넷의 모든 쌍이 경로 하나씩으로 이어진다(쌍마다 경로의 양 끝 노드로 확인). `tree`에서 보이는 경로의 수가 선명한 노드 수 − 1이다(고리 없음).

#### 3-2. `token-ring` — `TokenPassingDiagram`, JSON 키 `token-passing`

- 물음형 제목 예: `토큰 링에서는 누가 언제 보낼까?`
- 그릴 것: `RingPassDiagram`처럼 사각형 둘레의 `PC01`~`PC04`와 한 방향 링크 넷(직교 경로). 「토큰」은 노드가 아니라 곁말로 지금 누가 쥐었는지 보인다(또는 노드 곁의 작은 칸 노드 — 시나리오마다 다른 id·다른 자리).
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `circulate` | 토큰이 돈다 | 네 노드와 링크 넷 | 보낼 것이 없으면 토큰을 다음 노드로 넘긴다 |
  | `transmit` | 토큰을 잡고 보낸다 | `PC03`과 그가 보낸 데이터가 지나는 경로(`PC03` → `PC04` → `PC01`) | 토큰을 잡은 `PC03`만 정해진 시간 동안 보낸다(본문대로) |
  | `release` | 토큰을 넘긴다 | `PC03`·`PC04`와 `PC03` → `PC04` 경로 | 보내기를 마친 `PC03`이 토큰을 다음으로 넘긴다 |

- 요점 테스트: `transmit`에서 보이는 경로의 첫 시작 노드가 `PC03`이고 차례로 이어진다. 세 시나리오의 「선명한 노드 + 보이는 경로 + 보이는 곁말」이 서로 다르다.

위 도식 설계는 출발점이다. 본문(step 7 결과)과 맞지 않거나 280 폭에 들지 않으면 바꾸되, 바꾼 것과 이유를 summary에 적는다.
