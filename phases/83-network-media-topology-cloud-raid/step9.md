# Step 9: star-ring

## 배경

phase 83은 네트워크 과목의 `transmission-media`·`network-topology`·`cloud-sdn`·`raid-storage`를 만든다. 전체 계획·결정·공통 규칙은 `phases/83-network-media-topology-cloud-raid/guide.md`에 있다.
**이 step은 `network-topology`의 개념 둘(3 성형, 4 링형)의 글·문항·도식을 함께 만든다.** 둘 다 `network-topology`에 딸린 개념이다.

기출은 성형을 가장 자주 묻는다 — 중앙과 점 대 점으로 잇는다·단말을 더하고 빼기 쉽다·중앙에서 관리한다, 「단말 하나의 고장이 망 전체에 영향」이 틀린 말([기출 2024-05-19 #18]·[기출 2025-02-23 #20]·[기출 2026-08-02 #25]·[기출 2025-05-25 #20]·[기출 2026-02-01 #18]·[기출 2025-08-24 #22]).
링형은 「확장성이 뛰어나다」가 틀린 말이다([기출 2024-02-25 #19] — 시험이 맞는 말로 두는 셋의 처리는 step 7 결과대로).

### 3. 도식

#### 3-1. `star-topology` — `StarCenterFailureDiagram`, JSON 키 `star-center-failure`

- 물음형 제목 예: `성형에서 한 곳이 고장 나면 무엇이 멈출까?`
- 그릴 것: 가운데 `HUB01`, 위에 `PC01`·`PC02`, 아래에 `PC03`·`PC04`(280 폭에서 한 줄에 둘씩), 각 노드와 `HUB01` 사이 점 대 점 링크(늘 보이는 연결선), 통신 경로(`PC01` → `HUB01` → `PC04` 등 시나리오에만).
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `normal` | 중앙을 거쳐 | 모든 노드와 `PC01` → `HUB01` → `PC04` 경로 | 노드끼리의 데이터도 중앙을 거친다 |
  | `node-fail` | 노드 하나의 고장 | `PC03`을 뺀 노드와 `PC01` → `HUB01` → `PC04` 경로(`PC03`은 흐림) | `PC03`만 멈추고 나머지는 통신을 이어 간다 |
  | `center-fail` | 중앙의 고장 | 노드 넷(`HUB01`은 흐림), 통신 경로 없음 | 중앙이 멈추면 모든 노드가 통신하지 못한다(본문대로) |

- 요점 테스트: `node-fail`에서 `PC03`의 opacity가 0.25이고 `PC01` → `HUB01` → `PC04` 경로가 보인다. `center-fail`에서 `HUB01`의 opacity가 0.25이고 통신 경로가 하나도 보이지 않는다.

#### 3-2. `ring-topology` — `RingPassDiagram`, JSON 키 `ring-pass`

- 물음형 제목 예: `링에서 데이터는 어떤 길로 목적지에 닿을까?`
- 그릴 것: 사각형 둘레의 네 자리에 `PC01`(왼쪽 위)·`PC02`(오른쪽 위)·`PC03`(오른쪽 아래)·`PC04`(왼쪽 아래), 고리를 이루는 한 방향 링크 넷(직교 경로 — 원으로 그리지 않는다). 곁말로 도는 방향.
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `pass` | 차례로 거쳐 | 네 노드와 `PC01` → `PC02` → `PC03` 경로 | `PC02`가 받은 신호를 다시 만들어 다음으로 보낸다 |
  | `break` | 노드 하나의 고장 | `PC02`를 뺀 노드(`PC02`는 흐림)와 `PC01` → `PC02` 경로까지만 | 고리가 끊겨 `PC03`으로 가지 못한다(본문대로) |

- 요점 테스트: `pass`에서 보이는 경로가 `PC01` → `PC02` → `PC03`의 차례로 이어지고(경로 끝점이 다음 경로 시작 노드와 같다) `PC04`를 지나지 않는다. `break`에서 `PC02`의 opacity가 0.25이고 `PC03`으로 들어가는 경로가 보이지 않는다.

위 도식 설계는 출발점이다. 본문(step 7 결과)과 맞지 않거나 280 폭에 들지 않으면 바꾸되, 바꾼 것과 이유를 summary에 적는다.
