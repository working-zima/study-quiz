# Step 4: pon-impairments

## 배경

phase 83은 네트워크 과목의 `transmission-media`·`network-topology`·`cloud-sdn`·`raid-storage`를 만든다. 전체 계획·결정·공통 규칙은 `phases/83-network-media-topology-cloud-raid/guide.md`에 있다.
**이 step은 `transmission-media`의 개념 둘(5 FTTH와 PON, 6 전송 손상)의 글·문항·도식을 함께 만든다.** 둘 다 부모가 없는 개념이다. 5의 사실은 step 0이, 6의 사실은 step 3이 확인했다.

기출은 FTTH의 망 구조 가운데 PON을 고르게 하고([기출 2024-02-25 #25] — 지문 누락), 구리선에서 신호가 약해지는 감쇠([기출 2024-08-25 #20])와 주파수 성분마다 지연이 달라 생기는 위상 왜곡([기출 2025-08-24 #25]·[기출 2026-02-01 #23])을 묻는다.

## 읽어야 할 파일

- guide.md 「개념을 넣는 step의 공통 — 읽어야 할 파일」 전부. 그에 더해:

### 3. 도식

#### 3-1. `ftth-pon` — `PonSplitDiagram`, JSON 키 `pon-split`

- 물음형 제목 예: `광섬유 한 가닥을 여러 집이 어떻게 함께 쓸까?`
- 그릴 것: 위에 「통신사 설비」 그룹 박스 안의 `OLT01`, 가운데 「광 분배기」, 오른쪽(또는 아래)에 집 1~4의 ONU 노드 넷(세로로 쌓는다 — 280 폭에서 한 줄에 넷을 두지 않는다). `OLT01` → 광 분배기 경로 하나, 광 분배기 → ONU 넷 경로. PTP 시나리오용으로 `OLT01`에서 ONU마다 가는 따로의 경로 넷(분배기를 지나지 않게 다른 자리로 돌린다).
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `pon` | PON | `OLT01`·광 분배기·ONU 넷과 분배기를 거치는 경로 | 전원이 필요 없는 분배기가 한 가닥을 넷으로 나눈다(본문대로) |
  | `ptp` | PTP | `OLT01`·ONU 넷과 따로의 경로 넷 | 집마다 광섬유를 따로 하나씩 쓴다 |

- 요점 테스트: `pon`에서 ONU로 들어가는 보이는 경로가 모두 광 분배기에서 시작하고 `OLT01`에서 나가는 보이는 경로는 하나다. `ptp`에서 광 분배기 노드가 흐리고(0.25) `OLT01`에서 나가는 보이는 경로가 넷이다.
- AON을 본문에 썼으면 시나리오 `aon`을 더해도 된다(본문의 말대로) — 더했으면 summary에.

#### 3-2. `transmission-impairments` — `ImpairmentKindsDiagram`, JSON 키 `impairment-kinds`

- 물음형 제목 예: `신호는 매체를 지나며 어떤 손상을 입을까?`
- 그릴 것: 「보내는 쪽」 → 「매체」 → 「받는 쪽」 노드 줄(늘 보이는 연결선), 손상마다의 노드 — 감쇠는 「받는 쪽」 곁의 「약해진 신호」, 지연 왜곡은 받는 쪽 곁에 「먼저 닿은 성분」·「늦게 닿은 성분」 두 노드(서로 다른 자리), 잡음은 「바깥 잡음」 노드에서 매체로 오는 경로, 누화는 「옆 선로」 노드에서 매체로 오는 경로. 파형·곡선을 그리지 않는다.
- 시나리오:

  | id | label | 선명한 것 | 곁말·캡션이 말할 것 |
  |---|---|---|---|
  | `attenuation` | 감쇠 | 세 노드 줄과 「약해진 신호」 | 멀리 갈수록 세기가 줄어든다 |
  | `delay` | 지연 왜곡 | 세 노드 줄과 두 성분 노드 | 주파수 성분마다 걸린 시간이 달라 모양이 일그러진다 |
  | `noise` | 잡음 | 세 노드 줄과 「바깥 잡음」·그 경로 | 원치 않는 신호가 섞여 든다 |
  | `crosstalk` | 누화 | 세 노드 줄과 「옆 선로」·그 경로 | 옆 선로의 신호가 넘어온다 |

- 요점 테스트: 네 시나리오의 「선명한 노드 + 보이는 경로 + 보이는 곁말」이 서로 다르다. `noise`와 `crosstalk`에서 매체로 들어오는 보이는 경로의 시작 노드가 다르다. `delay`에서 두 성분 노드가 서로 다른 좌표에 있고 둘 다 선명하다.

위 도식 설계는 출발점이다. 본문(step 0·3 결과)과 맞지 않거나 280 폭에 들지 않으면 바꾸되, 바꾼 것과 이유를 summary에 적는다.
