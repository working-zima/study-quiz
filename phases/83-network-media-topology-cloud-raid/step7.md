# Step 7: topology-sources

## 배경

phase 83은 네트워크 과목의 `transmission-media`·`network-topology`·`cloud-sdn`·`raid-storage`를 만든다. 전체 계획과 결정은 `phases/83-network-media-topology-cloud-raid/guide.md`에 있다.
step 8~11이 `network-topology`의 개념 8개(네트워크 토폴로지, 버스형, 성형, 링형, 메시형과 트리형, 토큰 링, FDDI, IEEE 802 표준)를 쓰기 전에,
**이 step은 그 개념들이 쓸 사실을 허용한 출처로 확인하고 출처 문서에 남긴다.** 데이터·코드는 고치지 않는다.

이 주제의 사실은 IEEE 802(802.3의 동축·트위스티드 페어 구간과 리피터, 802.5 토큰 링, 802.4 토큰 버스, 802.1, 작업 그룹 목록)와 IETF RFC(토큰 링·FDDI의 MIB와 전송, 완전 메시의 수), ITU-T 용어 데이터베이스에서 가져온다(ADR-059).
기출 11문항이 모두 이 step의 개념에 걸린다 — 성형([기출 2024-05-19 #18]·[기출 2025-02-23 #20]·[기출 2026-08-02 #25]·[기출 2025-05-25 #20]·[기출 2026-02-01 #18]·[기출 2025-08-24 #22]), 링형([기출 2024-02-25 #19]), 버스형([기출 2024-08-25 #18]),
FDDI([기출 2024-11-03 #23]), 토큰 링([기출 2025-05-25 #27]), IEEE 802 짝([기출 2026-05-17 #22]).

## 작업

### 1. 확인할 것 — 하나씩 허용한 출처를 실제로 열어 확인한다

볼 곳: IEEE 802.3(`ieee802.org/3`의 공개 초안 — 1.4 정의(링크 구간·혼합 구간·point-to-point), 8·10장(동축 구간·터미네이터·탭), 9장(리피터 — 고장 난 포트를 떼어 놓는 partition·jabber), 13장(여러 구간을 이은 망의 구성 — 고리가 없는 모양이어야 한다는 말이 있는지), 14장(10BASE-T — 허브와 점 대 점 링크)),
`ieee802.org`의 작업 그룹 목록(활동 중·해산·쉼 — 802.1·802.2·802.3·802.4·802.5·802.6·802.11·802.15 등), `standards.ieee.org`의 802.5·802.4 개요 페이지(상태 — 철회 등),
IETF RFC(RFC 1748·1231(802.5 MIB — 링의 상태·비컨·삽입), RFC 1042(기존 항목), RFC 1512·1285(FDDI MIB — 이중 링·SMT·PHY·PMD·MAC·래핑의 상태 이름), RFC 1390·1188(IP over FDDI — 속도·프레임 크기), RFC 4456(완전 메시의 연결 수 n×(n−1)/2)),
ITU-T 용어 데이터베이스(topology·star·ring·bus·mesh network 등의 정의와 그것을 낸 권고).
**판을 적는다**. 응답이 느리면 `curl -4`로 다시 받는다. 유료 표준 본문(IEEE·ANSI X3T9.5·ISO 9314)은 열지 못하면 쓰지 않는다 — FDDI는 RFC가 말하는 만큼만.
**한국어 이름**: 토폴로지·물리·논리 토폴로지·점 대 점·다중점·버스형·터미네이터·반사·성형(스타형)·링형·메시형·완전 메시·부분 메시·트리형·토큰·토큰 링·토큰 버스·이중 링·1차 링·2차 링·래핑·비컨을 정하고 고른 까닭을 적는다(기출은 「성형」·「링형」·「버스형」·「Star」·「스타형」을 함께 쓴다).

### 3. summary — 뒤 step이 이것을 보고 쓴다

`network-topology`의 개념 1~8마다 한 줄씩(guide.md 「출처 step의 공통」의 summary 꼴). 특히 다음을 개념 step이 그대로 쓸 수 있게 적는다.
- 토폴로지의 뜻, 물리·논리를 쓸 수 있는지, 점 대 점·다중점의 말.
- 버스의 구간·터미네이터·반사·끊김. 성형의 점 대 점·고장 포트 떼어 놓기·중앙 고장. 링의 고리·재생·끊김·삽입·비컨.
- 완전 메시의 연결 수와 그 근거의 말, 트리와 고리 없음.
- 토큰 링·토큰 버스의 동작과 상태, FDDI의 이중 링·래핑·PMD·PHY·MAC·SMT·속도, IEEE 802 작업 그룹 번호와 상태 표.
- 기출 판정 줄: 성형 여섯, 링형, 버스형, FDDI, 토큰 링, IEEE 802 짝.
끝에 「사용자 확인」 칸 — 없으면 「없음」.
