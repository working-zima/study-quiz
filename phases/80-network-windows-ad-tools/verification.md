## 출처 step의 판정

- **E35**(step 0): [기출 2024-02-25 #41]의 RDS Endpoint Servers 설명이 문서와 어긋난다. 본문은 문서대로 한 줄 쓰고, 「자격시험은」 줄은 두지 않으며 문항에 그 그룹을 쓰지 않았다.
- **E36**(step 4): 자격시험은 `net user`를 도메인 사용자 계정을 관리하는 명령으로 보지 않고 `dsadd`·`dsmod`·`dsrm`과 가른다. 문서는 `/domain`을 붙이면 도메인 계정을 다룬다고 적는다. 본문은 문서대로 쓰고 「자격시험은」 한 줄을 두었다. 문항은 `/domain` 유무로 판정하지 않는다.
- **E37**(step 8): 자격시험은 `compmgmt`처럼 `.msc`를 뺀 이름을 실행되지 않는 것으로 본다. 본문은 실행 이름을 `.msc`까지 적고 「자격시험은」 한 줄을 두었다. 문항은 `.msc` 유무로 판정하지 않는다.
- **E38**(step 8): 자격시험은 CER·P7B·PFX·SST를 EFS가 지원하는 인증서 파일 형식으로 본다. 본문은 넷이 인증서 내보내기 형식이고 파일을 다시 열게 하는 것은 개인 키를 담는 .pfx라고 쓴 뒤 「자격시험은」 한 줄을 두었다. 문항은 그 말을 정답 근거로 쓰지 않는다.
- **사용자 확인**(step 8): 리소스 모니터의 탭 목록과 「네 자원을 실시간으로」가 허용한 문서에 없고 교육 과정 페이지에만 있다고 남겼다.
  step 11이 교육 과정 페이지를 쓰지 않고 다시 찾아 풀었다 — 지난 판 「Performance and Reliability Monitoring Getting Started Guide for Windows Server 2008」의 리소스 뷰 절(CPU·디스크·네트워크·메모리 네 자원, 프로세스별 값, 평균 CPU)과 지금 판 문제 해결 문서 둘. 사용자가 정할 것은 남지 않았다.
- 설계 때 적은 것과 다르게 쓴 것(step 0, 그대로 받아들였다): 「워크그룹」→「작업 그룹」, 「전이·비전이」→「전이적·비전이적 트러스트」.
  지금 판에 트러스트를 정의한 문서가 없어(how-trusts-work 404) 지난 판(Windows Server 2008)과 지금 판 세 문서를 맞춰 썼다.
- 근거를 찾지 못해 쓰지 않은 것: Power Users의 「옛 판 호환용」, 포리스트를 「보안 경계」로 부르는 말, 「트리 루트·부모-자식 트러스트」라는 이름, 리소스 모니터가 방화벽을 다룬다는 말, EFS 고급 특성 창의 확인란 이름(Microsoft Q&A 답변에만 있음), 클라우드 폴더 설치 차례의 「파일 및 iSCSI 서비스」(iSCSI를 풀 근거가 없어 「그 아래 항목에서」로만).
- step 13이 설계와 다르게 그린 것: BitLocker 도식의 「이 서버에서」를 TPM → 운영 체제 드라이브 → D:로 그렸다. TPM은 운영 체제 드라이브의 키를 내주고, 데이터 드라이브 D:는 운영 체제 드라이브가 보호되어 있을 때 저절로 열리게 하는 것이라(BitLocker FAQ) 「TPM이 D:를 연다」로 그리면 틀린다.
